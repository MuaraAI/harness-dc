# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of `harness-dc` seriously. If you discover a security vulnerability, please do **NOT** open a public issue.

Instead, please report it via one of the following channels:

1. **GitHub Private Vulnerability Reporting:** Submit a report via the [Security tab](https://github.com/MuaraAI/harness-dc/security/advisories/new) of this repository.
2. **Email:** Send details to [admin@muaraai.com](mailto:admin@muaraai.com).

### What to Include

Please provide:
- A description of the vulnerability and its potential impact.
- Step-by-step reproduction instructions or a minimal Proof of Concept (PoC).
- Affected platform/OS (Linux, macOS, Windows).
- Any proposed remediation if available.

### Response Timeline

- **Initial Acknowledgment:** Within 48 hours.
- **Triage & Status Update:** Within 5 business days.
- **Remediation & Patch:** Target within 14 business days depending on complexity.

Responsible disclosure guidelines apply. We appreciate your efforts in keeping the open-source community secure.
